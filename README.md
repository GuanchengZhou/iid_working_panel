# IID 科研工作台

一个在本机运行的中文科研工作平台，把文献阅读、项目跟进和审稿工作放在同一个网页中。使用 React、TypeScript、Vite、Fastify 和 SQLite；PDF、笔记、批注、会话及报告保存在本地。

当前支持三个模块：**文献整理、项目跟进、审稿工作**。日程安排仍为后续入口。

## 环境要求

| 组件 | 要求与用途 |
| --- | --- |
| Node.js / npm | Node.js **22.13 或更新版本**，推荐 Node.js 24；使用内置 SQLite |
| Codex CLI | AI 功能需要本机已安装并登录的 Codex CLI，以及对应模型权限；不使用 AI 时仍可导入、阅读和编辑 |
| Chromium | 仅动态网页资料采集需要，由 Playwright 安装 |
| Python 3 | 仅 DOCX、XLSX 等 Office 资料提取需要 |
| curl | 启动检测、备份服务检测及公开论文下载兼容处理使用；macOS 通常已提供 |

macOS 可使用双击启动脚本。其他环境可使用下面的命令行方式；浏览器访问本机地址。

## 安装与启动

```sh
git clone https://github.com/GuanchengZhou/iid_working_panel.git
cd iid_working_panel
npm ci
npm run build
npm start
```

打开 **http://127.0.0.1:4317/**。保持启动进程运行，按 `Ctrl+C` 停止。首次启动自动建立空白数据库；仓库不包含个人文献、项目、审稿样例或聊天数据，也不会自动启动示例 AI 检查。

需要采集动态网页时，再安装浏览器：

```sh
npx playwright install chromium
```

### macOS 双击启动

完成首次依赖安装后，双击 `启动工作台.command`。如果脚本缺少可执行权限：

```sh
chmod +x 启动工作台.command
```

脚本会在缺少依赖或前端构建时执行安装／构建；服务已运行时直接打开网页。关闭启动窗口会停止它所启动的服务。项目更新后应重新执行 `npm run build`，再重启后端。

### 配置 AI

先在本机完成 Codex CLI 登录并检查状态：

```sh
codex login
codex login status
```

程序优先检测 macOS ChatGPT 应用内置的 CLI，否则使用 `PATH` 中的 `codex`。也可指定完整路径：

```sh
IID_CODEX_BIN=/absolute/path/to/codex npm start
```

平台沿用 CLI 的 ChatGPT 登录，不要求在网页填写 API Key。可选模型为 `gpt-6-luna`、`gpt-6.1-sol`，思考强度为 `low / medium / high / xhigh / max`。默认 `gpt-6-luna / medium`；模型可用性取决于实际 CLI 和账号权限，失败会显示原因，不会静默替换模型。

普通助手的模型设置用于后续新任务；运行中任务保留创建时的设置。审稿模块为每一步独立保存模型和思考强度，不改变其他模块的默认值。

## 功能介绍

### 文献整理

- 单篇／批量上传 PDF，或通过 arXiv、OpenReview、公开 PDF 链接导入；单篇上限 80 MB，复制附件，不修改原文件。
- 提取可获得的标题、作者和摘要，支持修正元数据、会议／期刊、年份、标签、阅读状态、个人创新评分和手写 TL;DR。
- 按标题、作者、标签、TL;DR 搜索，按阅读状态及评分筛选和排序；通过文件哈希或论文标识识别重复。
- PDF.js 连续上下滚动阅读，支持缩放、翻页、文本搜索、阅读位置恢复、选文高亮及批注；归一化坐标适配缩放。
- Markdown 笔记自动保存，可插入 PDF 页码引用；Markdown 中支持行内公式、分式、矩阵和多行公式。
- 点击后生成论文分析：研究问题、创新、方法细节、对比实验、局限及 AI 创新评分；人工评分与 AI 评分独立，分析保留版本与证据匹配状态。
- OpenReview 分析可查询公开评论、决定和 Meta-review，保留来源快照；候选有歧义时等待选择，无法获取时可补链接或粘贴评论。
- 通用和论文专属 AI 会话持久化，可附加选文、笔记及已有分析。文献导入本身不调用 AI。

### 项目跟进

- 创建多个项目，设置目标、备注、P0–P3 优先级和归档状态；总览汇总进展、卡点、待办及未读动态。
- 管理待办、进行中、阻塞、已完成事项，支持可选截止日期和重新打开。
- 资料支持上传文件、绑定本地文件／目录、网页、背景文本、Codex 本地会话，以及 Inspire Notebook／Job。
- 读取 PDF、Markdown、文本、JSON、CSV、日志、Notebook、DOCX、XLSX 和常用图片；不支持的格式保留附件并显示限制。
- 每个项目有独立助手和报告历史。用户明确提供的网址／路径可通过会话导入；助手可按要求整理项目描述及资料元数据，修改留有前后记录和撤销入口。
- AI 对正式事项的增改与完成先生成建议，由用户确认后执行。助手不修改原始资料、不启停远端实验，也不获得任意 shell 或跨项目访问权限。

**自动跟进默认关闭。** 每个项目可以独立开启；开启后，仅在后端运行且存在活跃资料时每小时检查一次。每次都调用 AI，即使内容未变化。非活跃资料仅作为已有背景。关闭浏览器不影响运行中的后端；停止后端则停止跟进。重启或休眠后仅合并补查一次，不重放所有错过的小时。不安装开机服务，不发送系统通知。

资料限制：单个项目附件 20 MB；PDF 最多提取 200 页；文本单份最多约 22 万字符；目录默认扫描两层、最多 40 个文件。外部本地引用和远端结果不随附件备份自动复制。

Codex 会话资料可绑定 `codex://threads/会话ID`。仅读取明确绑定会话的用户消息和助手最终回复，保留最近消息快照，不读取系统提示、推理内容、工具输出或认证文件，也不执行来源会话中的命令。此功能依赖本机 Codex 存储格式，格式变化时可能需要适配。

Inspire 资料需要用户自行安装相应 CLI 并完成登录。平台仅读取所绑定资源的状态、日志和结果；网页需要登录或没有访问权限时保留引用，不把登录页当作正文，不自动复用浏览器 Cookie。

### 审稿工作

审稿材料与文献库独立，默认中文分析、英文审稿，可在每篇任务中调整。

1. **导入与配置**：上传 PDF，填写会议、截止日期、审稿要求和模板，选择每一步的模型及强度。
2. **一键初审**：查询公开版本、分析论文、生成英文初审候选，并分段检查 typo。各步骤可单独运行。
3. **版本查找**：应用查询 arXiv 和 OpenReview 公开接口，所选模型核对身份；用户确认候选后比较版本。支持补充网址和上传已下载的公开版本。
4. **问题备忘**：记录无位置的全局问题，或绑定页码、选文及坐标的问题；可编辑、分类、设置重要程度、核查状态与是否纳入审稿。
5. **草稿生成**：根据论文分析和所选问题生成 `Summary / Strengths / Weaknesses / Questions`。可增删、排序和编辑章节，预览 Markdown，自动保存、恢复历史并导出 `.md`。
6. **合理性检查**：检查误读、文章已有回答、证据不足、实验要求是否适当以及表述是否过强，并关联原文。
7. **润色与采用**：AI 重新生成及润色均形成候选，可整体或按章节采用，不直接覆盖手改稿；旧输入产生的候选会提示过期。

模板仅作结构和专业写法参考，不代表当前会议官方规范。评分栏目默认留空；提供明确尺度后 AI 才可建议数字，由用户填写或采用。平台不自动向会议／期刊提交审稿意见。

## AI 与任务的工作方式

任务保存输入版本、模型、强度、状态和结果，通过 SSE 更新页面。AI 工作默认串行执行，交互会话优先；支持停止、失败重试。服务重启后未完成任务标为中断，可手动重试。

Codex 以只读方式读取材料，关闭任意 shell 和应用集成；项目助手通过限定范围的工具访问资料及经授权的元数据编辑接口。论文、网页和会话内容作为材料处理，不作为系统指令。材料写入数据库由应用处理。CLI 按完成的消息事件更新内容，不保证逐 token 输出。

论文全文单次分析上限约 65 万字符。typo 检查按物理页分段保存，并进行跨页一致性检查。**原文匹配只证明引用存在，不证明 AI 结论正确。** 扫描稿不含 OCR，不能从提取文本可靠确认的图表、公式或视觉问题会保留核查限制。

## 本地数据与隐私

默认所有工作数据保存在项目根目录的 `data/`：

```text
data/
├── workbench.sqlite     # 文献、项目、审稿、笔记、会话及任务
├── pdfs/                # 导入的 PDF 副本
├── projects/            # 项目附件与资料
├── snapshots/           # 来源快照
├── contexts/            # AI 结构化输出配置
└── codex/               # 应用侧 Codex 相关文件
```

基础阅读与编辑可在离线状态使用。链接导入、公开版本查找和 AI 请求需要联网。**调用 AI 时，相应论文、选中的资料、问题或草稿会通过 Codex 发往其服务。** 动态网页采集会访问所绑定来源；界面字体无法联网时使用系统字体。

服务只监听 `127.0.0.1`，并检查 Host／Origin；当前设计为单用户本机使用，不提供远程账号系统。不要直接把后端暴露到公网。

仓库排除数据库、论文、附件、会话、备份、个人验收记录、截图、导出稿和认证配置。`.gitignore` 不会阻止强制添加文件，也无法清除已经发布的历史；提交前应检查暂存内容：

```sh
git diff --cached --stat
npm run check:public
```

个人项目初始化信息可选放在 `data/local-project-seed.json`，或用 `IID_PROJECT_SEED_FILE` 指向本地 JSON。该文件不随代码发布；已有安装的项目与资料从原数据库读取，初始化不会覆盖既有记录。配置缺省时不创建项目、不运行初始化 AI。多数用户直接在网页创建项目即可。

## 备份、恢复与迁移

先停止服务，保证数据库和附件一致，再运行：

```sh
npm run backup
```

备份写入 `backups/iid-时间.tar.gz`，包含数据库、附件和应用内快照，不包含本机 Codex 的认证令牌。备份含私人资料，请自行妥善存放，勿提交到代码仓库。

恢复前也须停止服务：

```sh
npm run restore -- /absolute/path/to/backup.tar.gz
```

恢复工具会校验归档及 SQLite 完整性，并把原数据保留为 `data.before-restore-时间`。外部绑定文件和目录仍引用原路径；换电脑后需重新绑定。恢复数据库中的 AI 消息仍可查看，但继续原 Codex 会话还需要相应本机 CLI 会话文件和登录状态。

更新代码推荐流程：停止服务 → 备份 → `git pull` → `npm ci` → `npm run build` → `npm start`。代码拉取不包含个人工作数据；不要使用会删除忽略文件的清理操作。

## 环境变量

使用启动命令的环境变量设置；程序不自动加载 `.env` 文件。

| 变量 | 默认值／作用 |
| --- | --- |
| `IID_PORT` | 后端端口，默认 `4317` |
| `IID_DATA_DIR` | 数据目录，默认当前工作目录下 `data` |
| `IID_CODEX_BIN` | Codex CLI 完整路径；其次读取 `CODEX_CLI_PATH`，再检测内置 CLI／PATH |
| `IID_PYTHON` | Office 解析的 Python 程序，默认 `python3` |
| `IID_CODEX_HOME` | Codex 会话资料的本地索引目录，缺省使用 `CODEX_HOME` 或用户的 `.codex` |
| `IID_SKIP_SEED` | 设为 `1` 时跳过可选的本地项目初始化 |
| `IID_PROJECT_SEED_FILE` | 可选的私有项目初始化 JSON 路径 |

改变端口后，浏览器来源限制也需要保持一致。当前允许的浏览器来源端口为 `4317 / 4318 / 5173`；macOS 启动脚本和默认开发代理固定指向 `4317`。自定义数据目录时，备份／恢复也须使用相同的 `IID_DATA_DIR`。

## 开发与检查

```sh
# 终端一：后端热重载
npm run dev

# 终端二：Vite 前端，默认 http://127.0.0.1:5173
npx vite

# 自动化测试与生产构建
npm test
npm run build
```

测试使用独立临时数据库和合成资料，不修改真实工作库。真实 AI 验证需要已有 CLI 登录及模型额度。生产运行只需 `npm start`，不必同时运行 Vite。

目录结构：

```text
src/          React 界面、PDF 阅读、Markdown 和公式显示
server/       Fastify 接口、SQLite、资料采集、Codex 队列
scripts/      项目范围工具、Office 提取、备份／恢复、发布检查
tests/        数据持久化、任务、资料隔离与渲染等自动化检查
```

## 常见问题

- **网页报无法连接服务**：确认 `npm start` 的窗口仍在运行，或重新双击启动脚本。检查本地代理是否影响回环地址。
- **页面没有显示新功能**：更新后执行 `npm run build`，重启后端，再刷新浏览器。
- **Codex 不存在／未登录／模型不可用**：检查 CLI 路径与 `codex login status`；使用有权限的模型。不支持的设置会明确报错。
- **动态网页采集失败**：先运行 `npx playwright install chromium`；需要登录的网页可导出文件后上传，或提供可访问链接。
- **PDF 下载超时**：重试，或下载后上传。本地导入不依赖远程下载成功。
- **Office 解析不可用**：确认 Python 3 可运行，必要时用 `IID_PYTHON` 指定路径。
- **某个任务重启后中断**：历史结果保留，在任务中重试。项目自动跟进只有开启开关后才补查。

当前不含云同步、Zotero 自动对接、OCR、自动提交审稿或日程业务实现。原始材料不被回写，AI 输出应结合原文判断。
